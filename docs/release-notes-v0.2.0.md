# FirstWindow v0.2.0 — Beginner Preview

Windows single-file preview for the **FirstWindow** beginner workflow.

1. Download `FirstWindow-Windows-x64.exe`.
2. Open it and press **Diagnose**.
3. Use **Set Up $0 Path** to prepare a verified free/local route.
4. Choose a project folder.
5. Describe what you want to build.
6. Press **Start Building**.

The default **$0 Mode** never silently falls back to a provider whose cost is unknown.

The Windows binary is currently unsigned, so Windows SmartScreen may show an unknown-publisher warning. The build pipeline runs a packaged self-test and prints a SHA-256 hash before publishing.
